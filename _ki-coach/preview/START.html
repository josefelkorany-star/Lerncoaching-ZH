KI-Coach von Lerncoaching ZH

Die korrigierte Arbeitsfassung liegt getrennt neben den vier unveränderten Originaldateien. Schüler- und Lehrpersonenmodus, Fachchats, Fotoauswahl, Gestaltung und Lernprinzip bleiben erhalten.

Korrigierte Arbeitsfassung öffnen

  1. Mit DEMO den Schülermodus öffnen, ein Fach wählen und einen Chat beginnen.
  2. Text in das Eingabefeld schreiben, ohne ihn zu senden. Abmelden und mit DEMO-LP anmelden: Der alte Text und die alte Liveansage werden gelöscht.
  3. Der schnelle Wechsel während einer laufenden Antwort ist automatisiert mit gezielt verzögerter Antwort geprüft: Sie darf die neue Sitzung nicht verändern. Die normale Demoantwort erscheint bereits nach etwa einer Sekunde.
  4. Die Lehrpersonenwerkzeuge, weitere Fachchats, Fotoauswahl und Dialoge sind weiterhin in der Originalgestaltung vorhanden.

Die Demo liefert feste Antworten, keine echte KI. Budgetreservierungen, Speicherung und Wiederholungen sind mit dem korrigierten Backend in getrennten automatisierten Tests nachgebildet. Die Demo allein weist keinen Google-/Claude-Betrieb nach. Bitte nur erfundene Inhalte verwenden.

Neu: gespeicherter Zugang und Codeersatz

Beim erneuten Öffnen bleibt die Ansicht gesperrt, bis der Zugang bestätigt ist. Bei fehlender Verbindung oder abgelehntem Code werden weder Namen noch gespeicherte Chats angezeigt. Danach gilt die aktuell bestätigte Rolle.

In der privaten Demo kannst du «Auf diesem Gerät angemeldet bleiben» wählen, einen erfundenen Chat beginnen und neu laden. Die Bestätigung kommt hier aus der Demo. Verzögerte, abgelehnte und fehlende Serverantworten sowie Rollenwechsel sind mit der tatsächlichen Arbeitsfassung automatisiert geprüft.

Der Codeersatz wird im Google-Verwaltungsmenü vorbereitet: Der alte Code verliert seine Gültigkeit, Tages- und Monatsverbrauch bleiben erhalten. Das wurde mit teilweise verbrauchtem Kontingent und nachgebildeten Google-Diensten getestet. Die Demo ist keine Google-Verwaltung. Bestehende lokale Chats werden nicht gelöscht; sie bleiben an ihren bisherigen Code gebunden und werden nicht automatisch auf einen neuen Code übertragen.
